# CassaFi for iOS and Android

The CassaFi mobile app is built with Expo SDK 57, React Native 0.86, Expo Router and TypeScript. It connects wallets through Reown AppKit with the wagmi adapter, so it uses the same signing flow as the web app at `/app`.

## What's in the app

| Screen | What it does, with live data |
|---|---|
| Welcome | The sign-in screen: Google, email, or any wallet over WalletConnect |
| Home | Wallet balance, your card, today's limits, recent on-chain activity |
| Pay | Policy checks, an EIP-712 authorization signed with your credential, then settlement from your wallet (or a relayer, once one is configured) |
| Activity | Full history for the address, paged as you scroll; tap a row to open it in the explorer |
| Card | Issue the spending credential with one signature, see the card, verify ownership, remove it from the phone |
| Settings (sheet) | Account, network (Robinhood Chain or Ethereum), daily limits, allowlist-only mode, sign out |

Robinhood Chain (4663) and Ethereum (1) are supported. Credentials, limits and authorizations are stored per address on the phone, using the same schema as the web app.

## Setup

```bash
cd mobile
npm install
cp .env.example .env   # then set EXPO_PUBLIC_REOWN_PROJECT_ID
```

The Reown project can be the same one the website uses. In the Reown dashboard, add the app's bundle IDs to the project's allowed list: iOS `money.cassafi.app`, Android `money.cassafi.app`.

## Run on your phone

```bash
npx expo start
```

Scan the QR code with Expo Go (Android) or the Camera app (iOS). Coinbase Wallet and native wallet detection need a development build instead of Expo Go.

## Build installable apps with EAS

Cloud builds don't need Xcode or Android Studio:

```bash
npx eas-cli@latest login
npx eas-cli@latest init                        # links the project to your Expo account
npx eas-cli@latest env:create --name EXPO_PUBLIC_REOWN_PROJECT_ID --value your_project_id --environment preview --environment production
npx eas-cli@latest build --profile preview --platform android   # installable .apk
npx eas-cli@latest build --profile production --platform ios    # needs an Apple Developer account
```

The build profiles are defined in `eas.json`.

## Checks


## Where things live

| What | Where |
|---|---|
| Screens (every file is a route) | `src/app/` |
| Design system: tokens, text, buttons, cards, logo, bank card | `src/theme/tokens.ts`, `src/ui/` |
| Wallet setup (AppKit + wagmi) | `src/wallet/` |
| Chain data, protocol and storage (ported from the web app) | `src/lib/` |
| Wordmark and card-network marks shared with the website | `src/ui/generated/` (run `npm run sync` after `npm run brand` in the website) |
| App icons and splash | `assets/images/`, generated by `scripts/export-brand.mjs` in the website |

The files in `src/lib/` mirror `src/dashboard/lib/` in the web app, so change the two together.
